# Transformer for German → English Machine Translation

PyTorch implementation of the Transformer architecture from **Attention Is All You Need** trained on the **Multi30k German → English** dataset.

This project includes:
- Noam Learning Rate Scheduler
- Scaled Dot-Product Attention
- Multi-Head Attention
- Positional Encoding
- Label Smoothing
- BLEU Evaluation
- Attention Visualization
- Extensive W&B Experiment Tracking
